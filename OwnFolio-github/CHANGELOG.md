# 更新记录

本文档记录本项目的所有重要变更。

## v1.0.0 — 2026-10-09

首个公开版本。

### 新增

- **两张表结构**：`项目库`（主表，存现状）+ `看法流水`（流水表，只追加、永不改旧行）
- **22个标准字段**，覆盖公司、赛道、轮次、状态、来源、兴趣度、投资逻辑、产品、竞争、财务、融资、可信度、我的看法、预测应验、跟进日期等
- **四种存储载体**：飞书电子表格、飞书多维表格、钉钉AI表格/在线表格、本地Excel/CSV、腾讯文档
- **静态看板**：一个HTML文件，含指标卡、行业分布、推进漏斗、季度节奏、同赛道横评、时间胶囊、打脸清单、该跟进了
- **两条工作流**：录入新项目、更新看法（追加一行并回填上一行的结果）
- **脏数据容错**：多种日期格式归一、非法打分忽略、枚举对不上时保留原值、同公司多行时保留最新
- **零依赖渲染**：`render_dashboard.py` 只用Python标准库，生成的HTML不引用任何外部框架、字体或图表库

### 设计取舍

- **不做模型接口，不做云同步**。使用者就是AI，AI本身就是大脑；数据落在用户自己的平台上，本项目不持有任何数据
- **看板是快照而非应用**。数据烤进HTML，离线可看、可转发，不需要服务端
- **历史不可改**。流水表只追加、只回填，这是时间胶囊和打脸清单成立的唯一前提
