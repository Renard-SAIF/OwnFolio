# 分析口径（写死，不许现场发挥）

同一个问题必须每次得到同一个答案。所有数字都由 `render_dashboard.py` 按本文件计算，
AI只负责**解读**，不负责算。

## 1. 预测命中率（打脸清单）

数据源：**看法流水表**（不是主表）。

```
已验证 = result 属于 {中了, 没中} 的记录数
命中   = result == 中了 的记录数
命中率 = 命中 / 已验证 × 100%（四舍五入取整）
```

- `result` 是"未验证"或"还没发生"的 **不计入分母**
- 已验证数为0时显示 `—`，**不要显示0%**（会误导）
- 分母太小时（< 5条）看板要标注"样本还少，别当真"

**口径为什么这样定**：预测写在流水表每一行的 `expect` 里，结果回填在同一行的 `result`。
一次看法对应一次预测，天然一对一，不会串。

## 2. 兴趣度均值

```
取主表所有 score 在 1-5 之间的项目，算算术平均，保留 1 位小数
非数字、空值、越界值不计入
```

## 3. 同赛道判定

`industry` 字段完全相同即同赛道。不做语义归并（"AI应用"和"AI应用"是同一个，
但"具身智能"和"机器人零部件"是不同赛道，不许自动合并）。

横评排序：**兴趣度从高到低**，同分时按交流日期新的在前。

## 4. 季度

自然季度，不看财年：
Q1 = 1-3月，Q2 = 4-6月，Q3 = 7-9月，Q4 = 10-12月。
季度归属按 `meetDate`（交流日期），没填交流日期的按 `createdAt`。

## 5. 时间胶囊

"回到N个月前的那段时间，看当时写下的原话"：

```
目标区间 = [今天 - N 个月, 今天 - N 个月 + 90 天]
取流水表里 at 落在这个区间内的所有行
```

可选回看时长：**6个月 / 12个月 / 24个月**。

显示"当时写的" + "后来的走向"两栏：
- 当时写的 = `view` + `expect`
- 后来的走向 = 该行 `result` 已回填就显示结果，没回填就显示
  "该项目的现状"（去主表取最新 `status`）

## 6. 该跟进了（看板顶部）

```
nextFollow <= 今天 且 status 不是 {已投, 已放弃}  → 逾期，标红
nextFollow 在未来 7 天内 且 status 不是 {已投, 已放弃} → 快到期，标黄
```

昨天没处理的**自动顺延到今天**，不会凭空消失。

## 7. 汇总指标卡（看板顶部四个）

| 卡 | 口径 |
|---|---|
| 共看过 | 主表项目总数（不含示例） |
| 已投 | status == 已投 的数量 |
| 平均兴趣度 | 见第2条 |
| 预测命中 · 已验N次 | 见第1条 |

## 8. 分布图

- **行业分布**：按 `industry` 分组计数，取前8，其余归"其他"
- **决策状态分布**：按 `status` 分组，顺序固定为枚举顺序（初次接触 → 已放弃），
  这样能看出漏斗形状，不许按数量排序

## 9. 颜色（国内习惯）

- 命中 / 正向 → 绿
- 没中 / 逾期 / 放弃 → 红
- 待观察 / 快到期 → 琥珀黄
- 中性 → 灰

## 10. 空数据

- 项目数为0：看板显示引导区（"还没有项目，把BP或会议纪要发给我"），**不编假数据**
- 某张图算不出数据：那张图整块隐藏，不要画一个空坐标轴
