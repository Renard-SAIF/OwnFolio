# 从材料提取字段的规范

输入可能是：一份BP（PDF/Word/图片）、一份会议纪要、一段语音转写、
用户随口说的一段话。目标都是同一件事：**落成主表一行 + 流水表一行**。

## 提取原则

1. **材料里有的才填，没有的留空**。绝不用常识补。
   - 材料没提估值 → `financing` 留空，不许写"估值不详"这类废话，更不许猜一个数字
   - 材料没提竞争对手 → `competitors` 留空
2. **必填项缺了必须回头问用户**（公司名、行业、轮次、状态、来源、兴趣度、一句话逻辑）
   - 其中 **兴趣度 `score` 材料里通常不会有**，直接问用户："这个项目你的兴趣度打几分（1-5）？"
   - **决策状态 `status`** 同理，问："现在推进到哪一步了？"
   - **项目来源 `sourceType`** 问："这个是谁推给你的？"
3. **日期归一**："上周三"、"9月初" 这类要换算成具体日期，换算不出就问用户。
4. **`thesis` 一句话投资逻辑**必须是**一句话**。材料里如果是一段，压缩成一句，
   完整内容放 `product` 或 `myView`。

## 提取后给用户的确认卡

不要默默写入。先给用户看一张卡，让他改：

```
公司：某某科技
行业：AI应用        轮次：C+轮        状态：深度尽调
来源：融资顾问推送（某 FA 机构）        兴趣度：5
一句话逻辑：某某细分数据市场庞大，已获头部模型公司背书
本轮融资与估值：本轮 1 亿美元，估值 10 亿美元
我的看法：短期看工程化能力，中期看纠错路线
当时的预测：半年内会拿到第二家头部模型公司的订单
下次跟进：2026-11-01

以上对吗？要改哪一处直接说。
```

## 字段与材料的对应关系

| 字段 | 通常从哪来 |
|---|---|
| `company` | 材料标题 / 封面 / 首段 |
| `industry` | 材料的行业自述，映射到默认词表；对不上就用原值当新赛道 |
| `round` | "本轮融资" / "本轮" 相关段落 |
| `thesis` | BP的"投资亮点" / 纪要的结论段 |
| `product` | "产品与技术" / "我们做什么" |
| `competitors` | "竞争格局" / "竞品对比" |
| `revenue` `financing` | 财务部分 / 融资历史 |
| `attendees` `meetDate` | 纪要抬头（时间、参会人） |
| `myView` | **用户自己的话**，材料里没有 → 问用户 |
| `expect` | **用户自己的预测**，材料里没有 → 问用户 |
| `credibility` | 默认是"创始人自述"；材料里有第三方数据佐证才升"部分验证" |

## 会议纪要的特殊处理

纪要里经常混着对方说的和你想的：

- **对方说的**（创始人介绍、数据、规划）→ 进 `product` / `revenue` / `financing`，
  并注意 `credibility` 默认按"创始人自述"处理
- **你自己说的/想的**（质疑、判断、结论）→ 进 `myView` 和 `expect`
- 分不清是谁说的 → 归到对方说的（保守），并提醒用户确认

## 更新看法时的特殊处理

用户说"我又聊了一次" / "我看法变了"：

1. 找出这个项目在流水表的**最后一行**，看它的 `expect` 有没有填、有没有结果
2. 如果上次的预测已经有结果了，先问："上次你说XX，后来怎么样了？"→ 回填 `result`
3. 然后**追加**新一行（新 `at`、新 `view`、新 `expect`）
4. 同步更新主表那行的 `myView` / `score` / `status` / `updatedAt`
5. **旧行一个字不动**
